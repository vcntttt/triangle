# T3 Code como fuente del contexto de desarrollo

Vicente desarrolla con T3 Code en todas sus máquinas, por lo que la integración se circunscribe a ese entorno en vez de incorporar seguimiento independiente del editor, la terminal u otras aplicaciones. Triangle reunirá información del trabajo repartido entre proyectos, máquinas y copias de trabajo; esta primera versión no ejecutará operaciones sobre Git ni detendrá servidores.

La prioridad es entender qué está ocurriendo ahora. La atención recibida se deducirá de actividad personal o de agentes durante los últimos siete días; abrir una conversación un instante no bastará. El tiempo personal será estimado y permanecerá separado de la ejecución de agentes.

La integración conservará un historial de cambios relevantes de Git, agentes y servidores. Los estados que ya existan al empezar a observar se fecharán como detectados desde ese momento, sin atribuirles una antigüedad que no puede comprobarse. La primera versión será de consulta, sin avisos proactivos.
