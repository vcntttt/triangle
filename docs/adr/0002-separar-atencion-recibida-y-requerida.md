# Separar atención recibida y requerida

El campo de atención de Triangle describe hoy cuánta atención necesita un proyecto y se selecciona manualmente. La integración con T3 Code observará además qué proyectos reciben trabajo, por lo que reutilizar ese campo para ambos significados haría que la actividad sustituyera la intención de Vicente.

Atención recibida y atención requerida serán conceptos independientes. Un proyecto puede requerir atención sin recibirla, recibir atención sin requerirla, tener ambas o ninguna. La actividad actualizará la atención recibida sin borrar la necesidad de atención declarada.
